# 当前产品要求

更新于 2026-11-11。本文记录用户最新决定，优先于此前独立 Chat 草案和三方群聊探索。

## 产品范围

- 从头重做 MOSS 语音 Chat 插件，以 DSH `0.2.2-rc.1` 的正式框架接口接入。
- 主对话只有用户与 MOSS。任务通过 DSH 原生子 Agent 委派执行；不做第二个常驻聊天成员或三方群聊。
- 委派携带目标与必要上下文，子 Agent 独立工作；进度、日志和结果可以查看。默认不让 MOSS 自动朗读其他 Agent 的正文，用户需要时再解释或总结。
- 复用 DSH 的配置、凭据、会话及子 Agent 能力，不另建聊天数据库或复制一套 Agent 系统。
- 系统提示词自动初始化，经 MOSS 官方 session 配置接口确认成功后再开始语音输入；按实际能力投影 DSH 提示词，避免宣称不存在的工具。

## 页面与交互

- 同一个插件内提供语音和文本历史两种会话视图，不做两套独立应用。
- 语音页新增 React 视图；文本历史优先复用 DSH 的会话与消息呈现能力。
- 使用 `conversation.view` 扩展视图；使用 `conversation.composer` 的正式替换机制提供语音会话专用输入区。通过 session 身份选择，避免影响其他普通 Agent 会话。
- 语音会话固定使用 MOSS 语音模型，关闭模型选择功能。不是仅隐藏选择器：会话逻辑也不能切到普通文本模型。
- 专用文本输入框视觉简化，去掉普通 Agent 输入栏中的模型、推理等复杂选择。普通 DSH 会话保留原输入栏；权限确认等必要框架交互不应被覆盖。
- 输入框的文字发送语义尚需验证：MOSS 当前公开实时协议尚未确认普通用户文字消息入口，不能擅自改为发给另一模型，也不能假装发送成功。
- 语音页与历史页切换时，当前语音收起为胶囊，继续连接、采集和播放。展开恢复同一次通话；只有明确结束语音、错误退出或插件释放时停止。
- 保留 DSH 原生的主会话与多个子任务视角切换、父子会话导航和任务执行记录。任务卡不能替代子任务视角；进入任何子任务时，主会话 MOSS 语音仍保持悬浮，支持返回主对话或展开同一次语音。
- 网络与媒体资源由插件控制器管理，独立于视图组件是否挂载；胶囊挂载在 `shell.overlay`。
- 不用 CSS 隐藏宿主组件，不扫描宿主文字，不通过 MutationObserver 插入宿主 DOM。

## 视觉和移动设备

- 参考 ChatGPT 实时语音模式；保留用户已认可的云蓝/极夜视觉方向、流体语音球和状态动效。
- 移动端为主要使用场景：窄屏、竖横屏、安全区、软键盘、触摸目标及历史滚动均需验证。
- 语音胶囊不得遮挡输入框或键盘。减少动态效果偏好、WebGL 不可用等情况需有适当降级。

## 插件设置

- 设置页集成到 DSH 的插件配置页面，修改通过原生 ConfigEditor 保存和校验，重新启动后恢复。
- 会话形象可选动态圆球或自定义图片。动态效果支持颜色、粒子数量、扩散程度；自定义图片支持圆形裁切。
- 语音模型从 DSH 已配置的模型中选择。API URL、Key 与端点适配类型统一在 DSH 原生 Models 页面管理，本插件不重复维护；第一版仅适配 MOSS，仅允许选择具备此适配能力的模型。
- 模型兼容判断不写死版本：MOSS 系列按不区分大小写的 `contains moss` 识别，并校验 provider 由 MOSS 端点适配器接入；`moss-live-2.0` 等后续模型 ID 原样传递，不改写成 1.0。协议差异由适配器处理或明确报错。
- 默认委托 Agent 从 DSH 已配置的 Agent 预设中选择，与主会话的固定语音模型分开。
- 2026-11-11 用户已确认大方向并明确授权开始：编写 Spec、Plan，并直接在本机 DSH 调整和测试，无须重复询问是否执行。
