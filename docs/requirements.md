# 当前产品要求

更新于 2026-11-11。本文记录用户最新决定，优先于此前独立 Chat 草案和三方群聊探索。

## 产品范围

- 从头重做 MOSS 语音 Chat 插件，以 DSH `0.2.2-rc.1` 的正式框架接口接入。
- 主对话只有用户与 MOSS。任务通过 DSH 原生子 Agent 委派执行；不做第二个常驻聊天成员或三方群聊。
- 委派携带目标与必要上下文，子 Agent 独立工作；进度、日志和结果可以查看。默认不让 MOSS 自动朗读其他 Agent 的正文，用户需要时再解释或总结。
- 复用 DSH 的配置、凭据、会话及子 Agent 能力，不另建聊天数据库或复制一套 Agent 系统。
- 系统提示词自动初始化，经 MOSS 官方 session 配置接口确认成功后再开始语音输入；按实际能力投影 DSH 提示词，避免宣称不存在的工具。

## 页面与交互

- 同一个插件内提供语音和文本历史两种会话视图，不做两套独立应用。
- 语音页新增 React 视图；文本历史优先复用 DSH 的会话与消息呈现能力。
- 唯一语音页面注册为原生 `main:moss`，不再注册重复的会话 MOSS 标签。文本历史使用原生 Chat，MOSS 主会话的 `conversation.composer` 只提供「返回语音」控制条；通过 session 身份选择，不影响普通会话和子任务。
- 语音会话固定使用 MOSS 语音模型，关闭模型选择功能。不是仅隐藏选择器：会话逻辑也不能切到普通文本模型。
- 历史页没有禁用的假文本输入框、模型/推理选择或重复错误；只有简洁的返回语音按钮。普通 DSH 会话保留原输入栏，权限确认等框架交互不被覆盖。
- MOSS 当前公开实时协议没有普通用户文字消息入口，因此不呈现文字输入；不能擅自发给另一模型或假装发送成功。
- 语音页与历史页切换时，当前语音收起为胶囊，继续连接、采集和播放。展开恢复同一次通话；只有明确结束语音、错误退出或插件释放时停止。
- 保留 DSH 原生的主会话与多个子任务视角切换、父子会话导航和任务执行记录。任务卡不能替代子任务视角；进入任何子任务时，主会话 MOSS 语音仍保持悬浮，支持返回主对话或展开同一次语音。
- 网络与媒体资源由插件控制器管理，独立于视图组件是否挂载；胶囊挂载在 `shell.bottom`。
- 不用 CSS 隐藏宿主组件，不扫描宿主文字，不通过 MutationObserver 插入宿主 DOM。

## 视觉和移动设备

- 参考 ChatGPT 实时语音模式，页面完全跟随 DSH 默认主题，不提供独立明暗切换。按钮、菜单、开关、输入框和图标复用官方 ui-primitives；使用 CSS Modules 与主题语义 token。
- 用 Three.js 绘制实心弹性球与吸附在外的云雾。球体必须有局部抓取、拉伸、体积保持及松手回弹；云雾具有持续演化的速度场，触碰施力会将雾推散、随后聚拢。物理指运动计算，不能仅用物理光照、全局缩放或噪声动画冒充。浓度控制雾粒子量，扩散控制分布及流体参数；支持鼠标/触摸、键盘与真实输入/播放音量反馈，设置预览同样可交互。
- 移动端为主要使用场景：窄屏、竖横屏、安全区、软键盘、触摸目标及历史滚动均需验证。
- 语音胶囊不得遮挡输入框或键盘。减少动态效果偏好、WebGL 不可用等情况需有适当降级。

## 插件设置

- 设置页在 DSH 设置左侧有独立「MOSS 语音」入口，修改通过原生 ConfigEditor 自动保存和校验，显示保存状态并处理修订冲突；重新启动后恢复。
- 会话形象可选动态圆球或自定义图片。动态效果支持颜色、粒子数量、扩散程度；自定义图片支持圆形裁切。
- API 完全用 DSH 默认方式配置，插件只选择原生目录中的一个模型；不提供独立 provider 配置表单，不按名称、版本或提供商筛选。模型 ID 原样传递；缺失配置提示「未配置」，实际协议不支持提示「不兼容」。第一版仅实现 MOSS 实时协议。
- 模型选择拆成「提供商」「模型」两个官方菜单，不添加可选的「未配置」项目。旁边有「测试连接」，实际验证鉴权、会话配置和音频协商；测试也尝试申请麦克风权限。麦克风使用「检测麦克风 / 停止检测」按钮与权限、音量状态，停止或离开设置页释放检测流；停止检测不能撤销浏览器已保存的授权。
- Agent 预设与委派执行模型分开选择；执行模型可显式选择原生模型或跟随 DSH 默认聊天模型。
- 连接失败显示简短原因与下一步，提供打开原生设置的快捷按钮。麦克风不存在、权限拒绝和占用分别给中文提示；历史页不重复显示同一错误。返回历史会话只改变查看目标，不停止另一个进行中的通话；按开始语音才切换连接。
- 侧栏入口使用顶部 `sidebar.panellist` 与配对 `main`，首页输入区通过 `conversation.input.right` 增加语音入口，不放在 footer。
- 2026-11-11 用户已确认大方向并明确授权开始：编写 Spec、Plan，并直接在本机 DSH 调整和测试，无须重复询问是否执行。
